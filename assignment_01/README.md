# Language Analytics - Assignment 1

## Project summary

This project is a descriptive linguistic profile of two NarraDetect subgenres: **Histories** (`HIST`) and **Memoirs** (`MEM`). The assignment asks how linguistic patterns vary across text groups, so the analysis compares the two genres using lexical, structural, named-entity, and sentiment-based measures.

The main research questions are:

1. How does lexical variation differ between Histories and Memoirs?
2. Do Histories and Memoirs differ in average sentiment?

The written report argues that the differences are moderate rather than categorical: memoirs show slightly higher TTR and more positive average sentiment, while histories show longer sentence structure and higher named-entity density.

## Data

The analysis uses the NarraDetect dataset. The full dataset contains 13,937 five-sentence excerpts across 18 genre labels. This project filters the data to:

- `HIST`: 1,004 excerpts
- `MEM`: 957 excerpts

This gives a final analysis set of **1,961 excerpts**.

Expected input file:

```text
data/narradetect.csv
```

The script expects at least the following columns:

- `genre`
- `text`

## Methods

The script parses the texts with spaCy and compares three preprocessing pipelines:

| Pipeline | Description |
|---|---|
| `RAW / minimal cleaning` | spaCy tokenization with spaces, invisible/control characters, and punctuation/symbol-only artefact tokens removed |
| `PLL` | punctuation removal, lowercasing, and lemmatization |
| `ALL` | stopword removal in addition to the `PLL` steps |

The core descriptive measures are:

- number of texts
- average text length
- number of tokens
- number of types
- type-token ratio (TTR)
- TTR on the first 100 tokens of each excerpt as a simple length-controlled check
- average characters per token
- average sentence length
- percentage of function words

The optional extensions are:

- VADER sentiment analysis at both excerpt level and sentence level
- named-entity density per 1,000 tokens

## Setup

Create and activate a virtual environment, then install the Python packages:

```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
pip install -r requirements.txt
```

The analysis uses the medium English spaCy model. Install it with:

```bash
python -m spacy download en_core_web_md
```

## Running the analysis

From the root of the assignment folder, run:

```bash
python src/main.py
```

The script will:

1. load `data/narradetect.csv`,
2. filter the data to `HIST` and `MEM`,
3. run the three preprocessing pipelines,
4. print compact summaries to the terminal,
5. save summary tables, and
6. save visualizations.

## Notes on interpretation

The minimally cleaned RAW pipeline is the most directly interpretable for the report, because stopword removal and lemmatization mechanically change values such as TTR and sentence length. The additional preprocessing pipelines are included to show whether the relative differences between genres remain stable under different preprocessing choices.

VADER and spaCy NER are useful descriptive tools, but their results should not be treated as definitive measures of emotion or reference. VADER is designed for modern evaluative language, and automatic NER may be less reliable for historical or older prose. The results should therefore be interpreted as descriptive tendencies within this dataset rather than broad claims about all memoirs and histories.
